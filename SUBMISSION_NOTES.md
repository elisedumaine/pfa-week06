# Submission Notes

## What to demonstrate

Capture a short screen recording (about 45–90 seconds):

1. Open **Tools → Open Interactive World Builder**.
2. Show the seed, density sliders, colors, and the Generate World button.
3. Generate the forest, then enter Play mode and move the template character.
4. Change tree or flower density and use **Refresh Plants** to show that the ground and lighting remain in place.
5. Save a preset, change a value, then load the preset back.
6. Use **Delete World** once to show a safe cleanup.

## Screenshots to include

- The full Editor Utility Widget with readable controls.
- One generated forest scene in the editor.
- One play-mode image with the Third Person character in the generated scene.
- Optional: before/after vegetation refresh using the same seed.

## Before submitting

- [ ] Open this project, not a new blank Unreal project.
- [ ] Close and reopen Unreal once if the widget still shows an older interface.
- [ ] Use a seed that produces your preferred forest and save its preset.
- [ ] Generate one final clean world for screenshots.
- [ ] Test Play mode: movement, camera, terrain, and path.
- [ ] Confirm no Output Log errors appear during the final generation.
- [ ] Commit/push the project source, `Config`, `Content`, `Plugins`, `.uproject`, and these Markdown files; do not include Unreal caches.
